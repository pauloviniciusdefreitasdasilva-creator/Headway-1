# Headway 1 · Elementary A1–A2

Twelve independent, responsive study guides based on the Headway Elementary 5th Edition syllabus.

## Each unit contains
- Detailed grammar, examples, vocabulary and pronunciation.
- Original unit opener and main MP4 video players.
- Original Student’s Book and Workbook MP3 players.
- A level-appropriate Conversation Lab with five topics, five questions per topic, vocabulary and useful chunks.
- Auto-checked grammar, vocabulary and reading practice, plus speaking and writing.
- Dark mode by default, with a persistent light/dark toggle.
- No fixed duration, lesson time or deadline.

## Course files
- `index.html`: course home and unit directory.
- `units/unit-01.html` … `units/unit-12.html`: separate unit guides.
- `data/course.json`: explanations, examples, exercises and unit video metadata.
- `assets/course.js` / `assets/course.css`: interactions and responsive styles.

## Media files required
The media binaries are not yet in this repository. Download both media archives and extract them into the repository root:
- Video Pack: 24 MP4s in `media/videos/` and `media/openers/`.
- Audio Pack: 169 Student’s Book MP3s, 64 Workbook MP3s and `media/audio/index.json`.

Then use GitHub Desktop to **Commit to main** and **Push origin**. GitHub Pages cannot serve media files that remain only in a local ZIP.

Detailed steps: see `media/README.md`.

## Study pace
There is no fixed duration or deadline for any unit. Students work at their own pace.

# Headway 1 · Complete Elementary Course

Single-site companion for Headway Elementary 5th Edition (A1–A2).

## Course contents
- All 12 units in one complete interactive course.
- Portuguese explanations, English model sentences, language forms, vocabulary and pronunciation notes.
- Automatic feedback for grammar, vocabulary, reading and cumulative review activities.
- Speaking and writing tasks, word counters and writing export.
- Browser speech synthesis with adjustable speed.
- Local progress and writing storage.
- Dark mode enabled by default, with a light-mode toggle.
- Responsive desktop, tablet and mobile layout.

## Files
- `index.html`: lightweight GitHub Pages entry point.
- `course-data/part01.txt` … `part08.txt`: eight base64 segments of the compressed course data. The loader joins, decodes and decompresses them in the browser.

The voice buttons use the browser/device English text-to-speech engine. They are not original publisher audio recordings.

## GitHub Pages
To publish: open **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/(root)`, then click **Save**. The site URL will be `https://pauloviniciusdefreitasdasilva-creator.github.io/Headway-1/` after GitHub Pages finishes the first deployment.

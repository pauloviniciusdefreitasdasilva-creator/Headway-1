# Headway 1 · Elementary A1–A2

12 independent learning guides for the Headway Elementary 5th Edition syllabus.

## In each unit
- Detailed grammar, examples and vocabulary.
- Original unit opener and main MP4 video players.
- Original Student’s Book and Workbook MP3 players.
- A level-appropriate Conversation Lab with topic prompts, question sets, vocabulary and useful chunks.
- Auto-checked practice, reading comprehension, speaking and writing activities.
- Dark mode by default, with a saved light/dark toggle.
- No fixed lesson duration or completion deadline.

## Project structure
- `index.html`: home and unit directory.
- `units/unit-01.html` … `units/unit-12.html`: independent guides.
- `data/course.json`: course content.
- `media/audio/index.json`: audio track map.
- `media/audio/student-book/`: Student’s Book tracks grouped by CD.
- `media/audio/workbook/`: Workbook MP3s grouped by unit.
- `media/videos/` and `media/openers/`: 24 unit MP4 files.
- `assets/course.css` and `assets/course.js`: presentation and interactions.

## Install all media
Download and extract both media archives into the repository root, preserving the `media/` folder:
1. Video Pack: provides `media/videos/` and `media/openers/`.
2. Audio Pack: provides `media/audio/` including `index.json`, 169 Student’s Book tracks and 64 Workbook tracks.

Then use GitHub Desktop to **Commit to main** and **Push origin**. GitHub Pages cannot serve media files that exist only on your computer or in a ZIP that has not been extracted and pushed to the repository.

## Study pace
There is no set duration, deadline or fixed time per unit. Students can progress at their own pace.
